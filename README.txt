# Emiser Logistic — Website

## Cum îl deschizi
1. Deschide folderul în Visual Studio / Visual Studio Code.
2. Deschide `index.html` în browser.
3. Pentru publicare gratuită poți folosi GitHub Pages, Cloudflare Pages sau Netlify.

## Înainte de publicare
În `index.html`, înlocuiește:
- numărul de telefon `+40 000 000 000`
- emailul `office@emiserlogistic.ro`
- eventualele texte/servicii cu datele reale ale companiei.

Fotografiile sunt momentan încărcate din Unsplash pentru demonstrație. Pentru varianta finală recomand fotografii reale cu flota Emiser Logistic.

Formularul folosește `mailto:` ca soluție simplă, fără backend. Pentru un formular profesional fără server, poate fi conectat ulterior la un serviciu precum Formspree/Netlify Forms.

Nu am inventat cifre despre companie; secțiunea de statistici folosește indicatori generici până când sunt introduse datele reale.
